01

Program the permission.

Approve an exact operation or grant a scoped session. Bind the recipient, per-operation limits, destination, and expiry to your application’s rules.

02

Separate the signing power.

The protocol’s target architecture uses two independent TEE signers. Each holds its own share. Neither share is sufficient to sign alone.

THE DESIGN PRINCIPLE

The full private key
never exists.

Key shares are created and used separately. The protocol combines signing contributions into a signature, without assembling a complete private key.

A property of the intended protocol execution, not a claim of immunity to compromise. Production hardware validation and independent construction review remain open.

A few things
worth knowing.

Can a Solidity contract control a PairKey key?

Solana is currently the only control plane. Solidity integration is planned and requires an explicit, verified path into Solana authorization. The current EVM adapter signs native transfers; arbitrary contract calls are not implemented.

Which chains work today?

Local end-to-end flows cover Solana and EVM native transfers. RedPallas signatures verify with Orchard SpendAuth verification, but a complete Zcash wallet and transaction pipeline are not implemented. NEAR uses a supported signature family; its transaction adapter and end-to-end flow are planned.

Are the two TEE signers deployed?

Not yet. Current tests use separate local processes with development identity receipts. Independent provider attestation, protected entropy, rollback resistance, recovery, and specialist cryptographic review remain production gates.

Does revoking a session invalidate a signature?

Revocation stops future issuance after the signers observe it. It cannot retract a signature already issued. Session limits are per operation; cumulative budgets and exactly-once destination execution are not provided.

What about passkeys and OIDC?

Local passkey assertion verification exists. Complete passkey onboarding and OIDC with ephemeral delegate keys are future integration work. Solana program authority remains the control plane.
