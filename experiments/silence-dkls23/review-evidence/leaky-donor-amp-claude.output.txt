# Findings
# 1. Detection probability of one injected inconsistency is 1 - 2^-j, where j is the
#    number of correlation-secret bits the receiver has NOT learned. Measured rates sit
#    on the 2^-j curve within binomial noise at 8192 trials.
# 2. The honest sender's consistency check has exactly one failure variant,
#    SoftSpokenOTError::AbortProtocolAndBanReceiver. The Rust compiler reports the
#    second error arm unreachable, so every rejection is the typed ban. There is no
#    silent-failure or untyped-error path.
# 3. j=0 (receiver already holds all 256 bits) accepts every tamper. This is not a new
#    weakness: it is the selective-abort model. The check's soundness rests entirely on
#    nabla staying hidden, and learning each hidden bit costs a guess detected with the
#    complementary probability.
# 4. Repairing with a different donor's secret accepts 0 of 8192. Bits learned from one
#    donor give no advantage against another's secret, so leakage does not compound
#    across generations. This is the cryptographic basis for discard-on-failure plus a
#    fresh donor: a detected miss both ends the current donor and resets the attacker's
#    knowledge to zero against the next.
