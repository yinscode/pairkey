PAIRKEY

04

The developer flow has three steps. Source: pick who controls the namespace, today a Solana program or a Solana account, with passkey and OAuth sources planned. Derive: add a derivation path and destination to get a public key, so one authority can hold many addresses on many chains, derived offline. Sign: call PairKey. Both signers authenticate the request, enforce current rules, and run the threshold protocol. The app gets back one signature plus identity-signed receipts it can verify.
