05

This is the core security idea. It is a 2-of-2 threshold: each signer holds a separate share, independently checks authorization, and contributes to the signature. In normal protocol execution the complete private key is never assembled anywhere, not in a signer, not in the coordinator, not in the client. The coordinator only routes encrypted protocol messages; it cannot replace either signer's checks. Be precise if asked: this describes protocol execution, and it does not protect against an attacker who extracts both shares.
