PAIRKEY

07

One authorization model, four signature schemes, five destinations. Solana and NEAR use FROST Ed25519. EVM chains use DKLS23 two-party ECDSA. Zcash uses FROST RedPallas. Bitcoin uses FROST secp256k1 with BIP-340 Schnorr output. All five are signing messages today on the hosted devnet deployment. Full transaction support beyond native transfers, such as ERC-20, EIP-1559 and Bitcoin transaction assembly, is separate roadmap work.
